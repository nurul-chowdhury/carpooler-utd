# Carpooler UTD

Carpooler is a student-focused carpool prototype designed for University of Texas at Dallas commuters.

## Prototype features

- Home-to-campus and campus-to-home ride matching
- University email verification concept
- Ride posting form for drivers and riders
- Privacy-first pickup zones
- In-app messaging and trip check-in concept
- Cost-sharing visibility
- CO₂ savings and student impact dashboard
- University setup panel to adapt the prototype to other campuses

## How to view

Open `index.html` in a browser, or publish this repository with GitHub Pages.
